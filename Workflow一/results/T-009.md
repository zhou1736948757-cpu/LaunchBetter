# T-009: probe counter semantics

## Status
PASS

## Changes
- `PagingInteractionController.displayFrameCount` and `scrollWriteCount` are now monotonic lifetime totals; `resetCounters()` leaves them intact while resetting the other probe diagnostics.
- Existing per-gesture baselines in `GridViewController` therefore remain valid when a second probe starts during an active settle; no negative subtraction or `max(0, ...)` masking was added.
- Documentation makes clear that processed-frame counts include probe processing, while real DisplayLink cadence remains separately measured by interval telemetry.
- Added an integration behavior test that starts a replacement probe during an active settle and verifies interrupted/replacement frame/write counts are nonnegative and isolated.
