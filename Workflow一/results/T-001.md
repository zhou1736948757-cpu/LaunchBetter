# T-001: 方向感知两页 PageCompositor + 第一页 PageVisual 准备

## 状态
完成。全部测试通过, `git diff --check` 干净。

## 目标
1. PageCompositor 以 2 页(current + direction neighbor)激活, 不再要求 3 页。
2. 第一页(currentPage == 0)可准备 PageVisual。
3. Page 1 → Page 2 首次手势可命中 compositor。

## 变更文件

### 源码
- `Packages/LaunchUI/Sources/LaunchUI/PagingInteractionController.swift`
  - 新增 `PagingDirection` 枚举(`previous` / `next`, `Sendable, Equatable`)。
  - 新增 `onWillStartHorizontalTracking: ((PagingDirection) -> Void)?` 回调。
  - 新增 `hasEmittedDirectionCallback` 标志, `beginGesture()` 重置。
  - `feedTracking` 在轴锁定后、首个非零水平位移时触发回调(deltaX<0→next, >0→previous), 在首次 offset 写入前; 不写 offset。
- `Packages/LaunchUI/Sources/LaunchUI/PageVisualCache.swift`
  - 新增 `visuals(for:displayRevision:geometry:backingScale:languageRevision:)` 显式页集合查询: 按请求序返回, 缺失项不返回(调用方以 count 检测不齐备), 忽略 iconEpoch 取最后插入者, 只读不提升 LRU。旧三页 API 保留为兼容。
- `Packages/LaunchUI/Sources/LaunchUI/GridViewController.swift`
  - `onWillBeginGesture` 接线改为 `onWillStartHorizontalTracking` → `tryActivatePageCompositor(direction:)`。
  - 拆分 `compositorSurfaceGate()`(方向无关表面/状态/密度门)与 `compositorCanActivate()`(诊断: 至少一个合法方向视觉齐备)。
  - 新增 `validDirectionTargets()` / `visualsReady(for:)` / `targetPage(for:)` / `isNearPageBoundary(_:)`(页宽归一化 + 0.01 容差, 无硬编码像素)。
  - `tryActivatePageCompositor(direction:)`: 表面门 + 目标合法邻页 + clip 在页边界 + 两页视觉齐备 → 激活; 否则 live 降级。compositor 已激活 → 不重建。
  - `performWorkingSetPrepare()`: 允许 currentPage == 0; 首页 [0,1], 末页 [last-1,last], 中间页 [c-1,c,c+1]。

## 证据指针
- 方向回调契约: `PagingInteractionController.feedTracking`(轴锁定后首个非零 deltaX 触发, 每次手势一次)。
- 两页激活: `GridViewController.tryActivatePageCompositor(direction:)` 用 `visuals(for: [currentPage, targetPage])` 且 `count == 2`。
- 首页准备: `performWorkingSetPrepare` 首页分支 `[0, 1]`。
- 页边界降级: `isNearPageBoundary` + `tryActivatePageCompositor` 的 clip 边界 guard。
- 测试: `PagingDirectionCallbackTests`, `PageVisualCacheTests`(T-001 段), `PageCompositorTests`(T-001 段), `PageCompositorGridIntegrationTests`(T-001 段)。
