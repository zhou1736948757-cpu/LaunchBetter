# T-008: settle telemetry lifecycle

## Status
PASS

## Changes
- Settle interruption/replacement duration is captured from the active settle start time; it no longer reads a stale completed-settle duration.
- Cancellation snapshots carry `nil` duration explicitly. `shutdown`, disable, `jumpTo`, cancelled wheel events, and animator replacement now close sessions with explicit cancellation/interruption lifecycle reasons.
- `liveFallback` remains an activation result only; completion reasons are settled/interrupted/cancelled.
- Animator replacement closes the old session before replacing the spring. Telemetry flush is guarded by the existing session lifecycle and therefore occurs at most once.
- Paging frame telemetry statistics/formatting/file output now run in a detached utility task; activation summary formatting remains detached and FIFO delivery is preserved.

- Added activation-fallback/completion-reason separation coverage.
- Added shutdown/disable/jump cancellation lifecycle coverage.
