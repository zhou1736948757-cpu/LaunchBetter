## Evidence Pointers

- `PagingFollowCurveTests` (10 tests) all pass:
  1. `testPositiveDirectionDamps` — positive displacement damped, direction preserved.
  2. `testNegativeDirectionDamps` — negative displacement damped, direction preserved.
  3. `testZeroPageWidthDoesNotCrash` — `max(1, pageWidth)` guard; zero/negative pageWidth finite.
  4. `testLargeDisplacementFiniteAndMonotonic` — huge input finite + monotonic.
  5. `testContinuity` — adjacent inputs → adjacent outputs.
  6. `testMonotonicity` — increasing displacement → increasing output (full sweep).
  7. `testFiniteValues` — no NaN/Inf incl. `.greatestFiniteMagnitude`.
  8. `testLinearMatchesCurrentBehavior` — linear 1.3 == `raw * PagingTuning.followSensitivity` (asserts `followSensitivity == 1.3`).
  9. `testDampedStrengthZeroEqualsLinearOne` — strength 0 == linear 1.0.
  10. `testDefaultCurveIsLinear13` — default curve is linear 1.3.

- Default preserved: `followCurve` default = `.linear(sensitivity: PagingTuning.followSensitivity)`; linear case computes `rawDisplacement * sensitivity` = `deltaX * 1.3`, bit-identical to the replaced `deltaX * PagingTuning.followSensitivity`.
