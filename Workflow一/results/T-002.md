# T-002: 关闭默认诊断热路径开销 + 激活原因遥测

## 状态
完成。全部测试通过, `git diff --check` 干净。

## 目标
1. 将 PageCompositor 的 per-frame 诊断开销从默认启用改为显式开启。
2. 增加纯值类型的 compositor 激活结果遥测, 默认不开启, `--pagingfeeltelemetry` 时启用。

## 变更文件

### 源码
- `Packages/LaunchUI/Sources/LaunchUI/PageCompositor.swift`
  - 新增 `diagnosticsEnabled = false` 显式开关; 默认产品路径 `recordEvent` 首行布尔判断即返回, 完全不进入记录逻辑。
  - `eventsForDiag` 改为固定容量(64)环形缓冲(`diagBuffer`/`diagStart`/`diagCount`), 不再调用 `Array.removeFirst()`; 对外仍暴露 `[Event]`(按时间序物化, 仅 diagnosticsEnabled 时非空)。
  - `applyOffset` 的 frame apply 计时改为 `metrics.enabled ? CACurrentMediaTime() : 0`, 默认产品路径不计算 frame apply duration。
- `Packages/LaunchUI/Sources/LaunchUI/PageCompositorActivationResult.swift`(新增)
  - 纯值类型 `enum PageCompositorActivationResult: Equatable, Sendable`, 13 个 case 区分最关键的失败原因。
- `Packages/LaunchUI/Sources/LaunchUI/PageCompositorActivationTelemetry.swift`(新增)
  - `@MainActor` 遥测记录器, 默认 `enabled = false`(各 record 方法首行布尔判断, 零开销路径)。
  - 热路径只写标量计数 + 固定容量(512)环形缓冲(真实 DisplayLink 间隔); 禁止每帧构建字符串 / 每事件写文件。
  - `flushGesture()` 在一次手势回到 idle 后异步格式化并输出摘要(不在帧预算内)。
  - 真实 DisplayLink 间隔经 `recordDisplayLinkInterval()`(displayTick 内)记录, 与 `recordProbeDisplayFrame()`(probeDisplayFrame)分开统计。
  - 摘要输出: gestureIndex / startPage / direction / firstGestureSinceShow / activationResult / cacheVisualCount / requiredPages / displayFrameCount / scrollWriteCount / settleDurationMs / displayLinkIntervalAvgMs / displayLinkIntervalP95Ms / displayLinkIntervalMaxMs。
- `Packages/LaunchUI/Sources/LaunchUI/PagingInteractionController.swift`
  - 新增 `onDisplayLinkTick` 回调(默认 nil, 产品路径零开销), 在 `displayTick()` 内调用; `probeDisplayFrame()` 不调用。
- `Packages/LaunchUI/Sources/LaunchUI/GridViewController.swift`
  - `pageCompositor.metrics.enabled` 与 `pageCompositor.diagnosticsEnabled` 改为仅 `--pagecompositor` 或 `--pagingfeeltelemetry` 时开启(不再 `= pageVisualCompositorEnabled`)。
  - 新增 `pageCompositorActivationTelemetry` 实例; `--pagingfeeltelemetry` 时启用并接线 `paging.onDisplayLinkTick`。
  - `tryActivatePageCompositor(direction:)` 保持激活逻辑不变, 仅在各返回点记录激活结果(观察者); 新增 `recordActivationResult` / `surfaceGateResult` / `visualsMissingResult` 辅助。
  - `onPhaseIdle` 接线 `flushCompositorActivationTelemetry()`: 按手势差分喂入 paging 的 displayFrame/scrollWrite 计数与 settle 时长, 再异步输出摘要。

### 测试

  - 新增: 默认 diagnostics 关闭不记录 / 显式开启有界记录 / metrics 默认关闭 / metrics 显式开启正确计数。
- `Packages/LaunchUI/Tests/LaunchUITests/PageCompositorActivationTelemetryTests.swift`(新增)

## 证据指针
- 默认诊断关闭: `PageCompositor.diagnosticsEnabled == false` + `recordEvent` 首行 guard; `PageCompositorMetrics.enabled == false` + `applyOffset` 计时 guard。
- 遥测观察者: `GridViewController.tryActivatePageCompositor` 各返回点仅 `recordActivationResult(...)`, 激活 guard 条件未变。
- 真实 DisplayLink 间隔分开: `PagingInteractionController.displayTick` 调 `onDisplayLinkTick`; `probeDisplayFrame` 不调。
- 测试: `PageCompositorTests`(T-002 段), `PageCompositorActivationTelemetryTests`。

## 与计划的偏差
- 无功能偏差。`firstGestureSinceShow` 由遥测内部跟踪(首次手势为 1, 之后为 0), 未接入 show 生命周期(最小改动)。
- `eventsForDiag` 采用固定容量环形缓冲(满足"优先 ring buffer"要求), 而非保留数组 + removeFirst。
