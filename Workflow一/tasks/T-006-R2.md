# T-006-R2: 为 telemetry FIFO 增加确定性异步顺序测试

## Objective
补足 Reviewer 指出的证据缺口：测试必须真实、确定性地让新 gesture formatter 先于旧 gesture formatter 完成，然后证明 delivery 仍按旧 gesture → 新 gesture 顺序。

## Existing Evidence
生产实现已有 `pendingSummaries` + contiguous-index drain FIFO；所有包测试通过。但 `.workflow/reviews/T-006-R1-r1.md` 指出当前测试仅启动两个 `Task.detached` 并 sleep，未控制完成顺序。

## Required Change
优先增加 internal/test-only 可注入的异步 formatter/scheduler seam，或等价的 deterministic gate：
- 生产默认路径仍使用异步 formatting；不把格式化移回 DisplayLink callback。
- 测试可以控制 gesture 0 formatter 延迟、gesture 1 formatter 先完成。
- 测试明确释放 gesture 1 gate，再释放 gesture 0 gate。
- 断言 summary callback 顺序为 gesture 0 → gesture 1。
- 断言两条 summary 都出现且 completionReason 保留。
- 不用 sleep 作为顺序证明，不用源码字符串断言。
- 不扩大 public API；seam 应为 internal/private 或测试注入点。

## Preserve
- MainActor snapshot capture and immutable Sendable snapshot.
- Sorting/p95/reduce/String formatting off final DisplayLink frame.
- Production FIFO behavior.
- T-005 coordinates and all prior T-006 behavior.
- Flag isolation test.
- No commits/push/releases.
