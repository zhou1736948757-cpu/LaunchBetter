## Implementation Details

### PageCompositorMetrics 默认关闭

不得再使用：
```swift
pageCompositor.metrics.enabled = pageVisualCompositorEnabled
```

建议由以下任一条件控制：
- `--pagecompositor`
- `--pagingfeeltelemetry`

测试可以通过内部 seam 显式启用。

默认产品运行时：
- 不计算 frame apply duration。
- 不更新 frame metrics。
- 不做与指标有关的格式化或数组操作。

### eventsForDiag 默认关闭

增加显式开关：
```swift
var diagnosticsEnabled = false
```

只有测试或诊断 probe 显式开启时，才记录：
- activated
- applied
- finished
- aborted
- shutdown

如果保留 64 项事件窗口：
- 优先使用真正的固定容量 ring buffer。
- 不允许在每个满载 display frame 中调用 `Array.removeFirst()`。
- 如果为控制改动量继续使用数组，至少必须保证默认产品路径完全不进入记录逻辑。

更新现有测试，让依赖 `eventsForDiag` 的测试显式开启诊断。

### 激活原因遥测

新增纯值类型：
```swift
enum PageCompositorActivationResult: Equatable, Sendable {
    case activated
    case disabled
    case alreadyActive
    case search
    case appLibrary
    case dragActive
    case sparsePage
    case offsetNotAtBoundary
    case targetIsLibrary
    case targetOutOfBounds
    case currentVisualMissing
    case targetVisualMissing
    case invalidGeometry
}
```

具体命名可按现有代码风格调整，但必须能区分最关键的失败原因。

要求：
- 产品默认不开启聚合和日志。
- `--pagingfeeltelemetry` 时启用。
- 热路径只写固定容量计数器或环形缓冲。
- 禁止每事件写文件。
- 禁止每帧构建字符串。
- 在一次手势回到 idle 后，再异步格式化和输出摘要。
- 不得让 telemetry 改变 compositor 激活判断。

至少输出：
```text
gestureIndex
startPage
direction
firstGestureSinceShow
activationResult
cacheVisualCount
requiredPages
displayFrameCount
scrollWriteCount
settleDurationMs
```

如果能安全取得，还应记录：
```text
displayLinkIntervalAvgMs
displayLinkIntervalP95Ms
displayLinkIntervalMaxMs
```

真实 DisplayLink callback interval 必须和手工调用的 `probeDisplayFrame()` 分开统计。

## Acceptance Criteria

1. 默认产品路径不记录 compositor per-frame diagnostic events。
2. 默认产品路径不计算 compositor frame metrics。
3. `--pagingfeeltelemetry` 可启用完整遥测。
4. 热路径只写固定容量计数器或环形缓冲，禁止每帧构建字符串。
5. 遥测不改变 compositor 激活判断。
6. 依赖 eventsForDiag 的测试已显式开启诊断。
7. 不得让 telemetry 改变 compositor 激活判断。

3. `--pagingfeeltelemetry` 启用后输出正确摘要格式。
4. 真实 DisplayLink interval 与 probeDisplayFrame 分开统计。
