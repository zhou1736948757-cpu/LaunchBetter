# T-005: P0 — 修复 PageVisual 合成层坐标 (gridOrigin)

## Task ID: T-005
## Priority: P0
## Status: READY

## Objective

PageCompositor 合成层 placement 遗漏了 `gridOrigin.x/y`，导致 compositor layer 相对真实 Cell 向左上偏移。必须在 placement 阶段加回 gridOrigin。

## Root Cause

真实 Cell 的 document frame = `pageOrigin + gridOrigin`。
PageVisualRenderer 把 cell frame 转换为图片局部坐标时减去了 `gridOrigin`，返回 `logicalBounds.origin == .zero`。
但 GridViewController 构造 compositor placement 时只计算了 `leadingDocumentOffset + page * pageWidth + bounds.minX`，遗漏了 `g.gridOrigin.x` 和 `g.gridOrigin.y`。

## Must Read

- `Packages/LaunchCore/Sources/LaunchCore/GridGeometry.swift` — 理解 frame 计算
- `Packages/LaunchUI/Sources/LaunchUI/PageVisualRenderer.swift` — 理解坐标转换
- `Packages/LaunchUI/Sources/LaunchUI/GridViewController.swift` — 当前 placement 构造（已含 T-001~T-003 改动）
- `Packages/LaunchUI/Sources/LaunchUI/PageCompositor.swift` — Placement 类型
- `Packages/LaunchUI/Sources/LaunchUI/PageVisual.swift` — logicalBounds 含义

## Fix

在 `GridViewController.swift` 构造 `PageCompositor.Placement` 时，使用完整 document rect：

```swift
let documentRect = CGRect(
    x: leadingDocumentOffset
        + CGFloat(item.page) * g.pageWidth
        + g.gridOrigin.x
        + bounds.minX,
    y: g.gridOrigin.y + bounds.minY,
    width: bounds.width,
    height: bounds.height
)
```

优先使用 `collectionView.convert(documentRect, to: view)` 而不是只转换 origin 后沿用 size。

`baseFrame` 必须与真实 Cell 所处的 grid content rect 对齐。

不要修改 `PageVisual.logicalBounds` 的含义。首选方案是在 placement 阶段加回 `gridOrigin`。

## Required Tests

在真实 Grid 集成测试中覆盖：

1. 创建非零 `gridOrigin.x/y` 的 GridViewController。
2. 使用真实 PageVisualRenderer prepare 页面视觉。
3. 激活 compositor。
4. 取得 `pageCompositorLayerFramesForDiag`。
5. 根据以下数据独立计算预期 frame：`leadingDocumentOffset`、`pageIndex * pageWidth`、`geometry.gridOrigin`、`visual.logicalBounds`、`collectionView.convert(..., to: view)`。
6. 断言 layer frame 与预期 frame 在小浮点容差内相等。
7. Page 0→Page 1、普通中间页和末页至少各覆盖一个场景。
8. 不能只断言 layer 数量、opacity 或 page index。

## Acceptance Criteria

1. compositor layer frame 与真实 grid content frame 完整对齐。
2. `gridOrigin.x/y` 非零时没有激活跳变。
3. 不存在 double-offset 或 leadingDocumentOffset off-by-one。
4. 测试验证真实坐标而非仅 layer 数量。
