# T-010: 真实 active compositor interruption 集成测试

## Objective
补齐 GridViewController + PageCompositor 的真实集成证据；不得仅用 PagingInteractionController 单测替代。

## A. Missing coverage → Page 3 live fallback
测试必须：
1. 从 Page 1 开始，真实 Page 1 → Page 2 compositor settle。
2. 用 deterministic clock 推进到两个 page boundary 之间。
3. 保存 interruption 前 compositor.currentOffset。
4. 第二次同方向手势真实解析并继续到 Page 3；禁止净位移为零或最终回 Page 2 的输入。
5. coverage missing 后立即断言 compositor inactive、live opacity=1、clip 与 abort 前 currentOffset 连续、可见内容非空、无同步 PageVisual/cache 等待。
6. 完成第二次 settle。
7. 最终断言 currentPage == 3、clip == Page 3 offset、无残留 layer、live content 非空。

## B. Covered reverse → compositor reuse
1. 真实 Page 1 → Page 2 compositor settle，推进到 mid-settle。
2. 第二次反向 tracking，新目标仍在覆盖集合。
3. compositor 始终 active；无 abort；layer identity/stable id 不重建；live 不提前显示；offset 连续；最终目标正确；收尾清理正常。

## C. Boundary interruption
覆盖 active settle 中途进入 App Library、末页向越界方向；boundary fallback 后 live 非空；无越界 page key；不构建缺失 visual。

## Constraints
不改生产行为迎合测试；不改坐标、motion writer、PagingSpring、默认手感、100ms debounce、ownership、`advanceRealClipBehindCover()`；不自动 commit/push/release。
