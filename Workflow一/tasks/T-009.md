# T-009: 修复 probe counter 语义

## Objective
保证 telemetry 的 displayFrameCount / scrollWriteCount 不因 probe reset 产生负值或 session 间污染，并区分真实 DisplayLink 与 probe frame。

## Required
1. probe reset 不导致旧 session 负 count。
2. 优先在 reset 前结束并 flush 旧 session，或改为永不归零的单调总计数 + session baseline。
3. 禁止 `max(0, value)` 掩盖生命周期错误。
4. 区分真实 DisplayLink frame 与 probe frame；若不新增字段，不能作出虚假声明。

## Tests
- settle 中启动第二次 probe gesture。
- old/new session 所有 count 非负。
- 两个 session count 不互相污染。
- 真实 DisplayLink 与 probe 的既有分离测试继续通过。

## Constraints
不改 PagingSpring、默认 linear、normalizedDamped opt-in、motion writer、100ms debounce、PageVisual 坐标、ownership 或 public API；不自动 commit/push/release。
