# T-008-R1: tracking teardown telemetry cancellation

## Blocker
`Workflow/reviews/T-008-r1.md` F1/F2：tracking-only `shutdown`, `isEnabled=false`, `jumpTo` 会进入 idle 后由 Grid 的默认 onPhaseIdle 按 settled flush，缺少 cancelled 语义。

## Required
1. 任何 active tracking telemetry session 在 shutdown、disable、jumpTo 时明确以 `completionReason=cancelled` flush。
2. 不影响 settling 的 interrupted/cancelled 语义。
3. cancelled duration 使用 nil/明确语义，不复用旧 settle duration。
4. 每 session 仍最多 flush 一次。
5. 增加真实端到端行为测试：GridViewController + PagingInteractionController 开始 active horizontal tracking 后，分别执行 shutdown、isEnabled=false、jumpTo，断言 summary 的 completionReason=cancelled。
6. 如 cancelled NSEvent 路径已有/缺失，也补真实行为覆盖，但不扩大架构。

## Preserve
异步 formatting/FIFO、T-005 坐标、T-009 未开始的 counter 语义、PagingSpring/default linear/normalized opt-in、100ms debounce、ownership、advanceRealClipBehindCover、无 public API 扩张。
