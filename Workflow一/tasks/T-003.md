## Implementation Details

### PagingFollowCurve

```swift
public enum PagingFollowCurve {
    case linear(sensitivity: CGFloat)
    case normalizedDamped(strength: CGFloat)
}
```

归一化阻尼必须以 page width 为尺度：

```swift
let normalized = abs(rawDisplacement) / max(1, pageWidth)
let damped = rawDisplacement / (1 + strength * normalized)
```
