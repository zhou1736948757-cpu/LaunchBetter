# T-008: 修复 settle telemetry 生命周期

## Objective
只修复遥测生命周期语义，不重写分页架构、不调整默认手感。

## Required
1. interrupted settle 记录当前 settle 实际持续时间；不得复用上一次 `lastSettleDuration`。
2. 无法定义 duration 的取消路径使用明确 nil/optional 语义，不静默复用旧值。
3. shutdown、isEnabled=false、jumpTo、NSEvent cancelled、animator replacement 明确且一致地标记 `settled | interrupted | cancelled`。
4. `liveFallback` 只作为 activation outcome，不进入 completionReason。
5. startSettle 替换已有 settle target 时，旧 session 必须明确 interrupted/cancelled 并 flush，或明确建模为同一 session replacement；不得静默合并 duration/frame/write。
6. 每个 session 最多 flush 一次。
7. 摘要格式化、排序、p95/reduce 不得在主线程或最终 DisplayLink callback 执行。
8. 保持 formatter 乱序完成时的 FIFO delivery。
