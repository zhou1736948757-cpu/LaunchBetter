# T-006-R1: 修复 telemetry summary FIFO 顺序与 flag 行为测试

## Objective
修复 T-006 Reviewer 发现的唯一 BLOCKER，并补足 flag isolation 行为测试。

## Evidence
`.workflow/reviews/T-006-r1.md`：异步 detached formatting tasks 无序完成，interrupted gesture index 0 的摘要可能晚于新 gesture index 1，导致 LaunchUI 测试失败。

## Required Fix
- 保持 snapshot 在 MainActor 捕获。
- 保持排序/p95/reduce/String formatting 不在最终 DisplayLink callback 执行。
- 为异步 summary formatting 增加 FIFO delivery 机制，确保 gesture summary 按 gestureIndex/session sequence 顺序回调；不可通过重新同步格式化到 DisplayLink 帧解决。
- 不允许旧 session 被新 session 覆盖或丢弃。
- 保持 completionReason。

## Required Test
修复并保留 interruptedFlushPreservesOldSession 行为测试，证明：
1. interrupted gesture summary 最终产生；
2. 新 gesture summary 最终产生；
3. 回调顺序为旧 gesture 在前、新 gesture 在后；
4. formatting 仍是异步完成。

增加真实行为的 flag isolation 测试：
- `--pagecompositor` 开启 metrics/events，但不要求 paging telemetry；
- `--pagingfeeltelemetry` 开启 activation telemetry/DisplayLink interval/summary，但不自动开启 PageCompositor metrics/events；
- 两者同时存在时两组都开启。
如命令行状态不适合直接构造，使用现有 internal seam/configuration seam，不写源码字符串断言。
