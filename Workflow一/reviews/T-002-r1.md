### MINOR

1. **`recordEvent(.applied(offset: offset))` call site not guarded in hot path.**
   `applyOffset` (line 241) calls `recordEvent(.applied(offset: offset))` every frame even when `diagnosticsEnabled == false`. The `recordEvent` method's first-line `guard diagnosticsEnabled else { return }` prevents any recording, but the enum value `.applied(offset: offset)` is still constructed on each frame. This is a stack-allocated value type (negligible cost), and the guard prevents all recording logic. Strictly speaking, the task says "默认产品路径完全不进入记录逻辑" — the function call + guard is entered, though no recording occurs. This is acceptable given the value type's zero heap cost, but a call-site guard (`if diagnosticsEnabled { recordEvent(.applied(offset: offset)) }`) would be more defensive.

2. **`firstGestureSinceShow` semantics differ from name.**
   The telemetry tracks `firstGestureSinceShow` as "first gesture since telemetry was enabled" (initially `true`, set to `false` after first `flushGesture()`), not "first gesture since grid view was shown." The worker documented this deviation. Since `--pagingfeeltelemetry` is opt-in, this is the first gesture since the flag was set, which may not coincide with view show. The field is still output and the deviation is documented.

## Recommendation

PASS. The implementation correctly:
- Defaults diagnostics and metrics to off in the product path
- Uses a fixed-capacity ring buffer (no `Array.removeFirst()`)
- Implements telemetry as a pure observer (no activation logic changes)
- Separates real DisplayLink intervals from probe frames
- Outputs summaries async after gesture idle
- Explicitly enables diagnostics in all existing tests that depend on `eventsForDiag`

The two MINOR findings (unguarded `recordEvent` call site in hot path, `firstGestureSinceShow` semantics) do not block acceptance. The call-site guard is a micro-optimization (enum is stack-allocated, guard in method prevents all recording), and the `firstGestureSinceShow` semantics are documented and do not affect correctness.
