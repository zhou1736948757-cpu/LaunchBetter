## 1. 背景（GPT 分析 P2，Chief 采纳方向）

`Packages/LaunchPlatform/Sources/LaunchPlatform/IconContentVersionFactory.swift` 现状：每个候选 URL 做**两次** `resourceValues` 调用（`modificationNanoseconds(of:)` 取 contentModificationDateKey，`fileSizeBytes(of:)` 取 fileSizeKey），两个调用点（:27 iconFile、:40 Assets.car）。合并为一次调用，代码更少且减少文件系统元数据查询。

## 2. 方案

```swift
private static func resourceMetadata(of url: URL) -> (mtime: UInt64, size: UInt64)? {
    guard let values = try? url.resourceValues(
        forKeys: [.contentModificationDateKey, .fileSizeKey]
    ), let date = values.contentModificationDate, let size = values.fileSize else {
        return nil
    }
    return (UInt64(date.timeIntervalSince1970 * 1_000_000_000), UInt64(size))
}
```

- 删除 `modificationNanoseconds(of:)` 和 `fileSizeBytes(of:)` 两个私有函数
- 两个调用点（:27/:40）改为 `resourceMetadata(of:)` 一次调用 + 解构
- 返回的 mtime/size 语义与现在逐位一致（同一公式）
- 行为零变化：命中/回退路径、IconContentVersion 字段、信号优先级（§74）不变
