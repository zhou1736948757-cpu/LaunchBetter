## 1. 背景

compositor ON 时，滑动过程中 app 图标+名字**上下镜像翻转**（位置不变），
滑动结束/停稳后恢复。每个页面均出现；仅 compositor ON 的变体出现
（T-016 60Hz 轮 R2/R3 用户确认；R1/R4 compositor OFF 无）。

## 2. 根因证据（文件:行号，T-016 已定位 + Reviewer 独立实验证实）

- **根因行**：`Packages/LaunchUI/Sources/LaunchUI/PageCompositor.swift:191`
  `layer.isGeometryFlipped = true` → CALayer 垂直翻转 contents 渲染。
- **机制**：
  1. `PageVisualRenderer.rasterize`（PageVisualRenderer.swift:308-326）用
     y-down 变换（translate + scale(1,-1)）光栅化，**图像本身方向正确**
     （PageVisualRendererTests.swift:101-107 逐像素断言验证）。
  2. `PageCompositor.activate`（:186-202）创建 CALayer 并设
     `isGeometryFlipped = true`（:191）→ contents 垂直镜像。
  3. 宿主层 = `view.layer`（GridViewController 的 view，**非 flipped，y-up**）；
     `baseFrame` 由 `collectionView.convert(documentRect, to: view)` 计算
     （GridViewController.swift:1672），PageCompositor.swift:104 注释明确
     "baseFrame 为宿主层坐标, y-up" → frame 位置正确（"位置不变"的原因）。
  4. live 路径 `AppCellView.iconLayer`（AppCellView.swift:44, 656）为
     **非 flipped** CALayer，方向正确（用户确认）。
  5. activate 时 `liveLayer.opacity = 0`（:201）→ 用户只见镜像合成层；
     teardown（finishSettle/abort/shutdown，:283-297）同步 clip →
     `liveLayer.opacity = 1` → 移除合成层 → "停稳恢复"。
- **独立实验**：`Workflow/evidence/T-016/analysis/calayer-flip-experiment.swift`
  （Reviewer 编译运行）：`isGeometryFlipped = false` → contents 正向；
  `isGeometryFlipped = true` → 垂直镜像。
- **测试缺口**：PageVisualRendererTests 只断言图像像素，无任何测试渲染
  合成层验证显示方向。

## 4. 方案决策（Chief 已定，Worker 不得自行切换）

### 推荐：方案 A —— 移除 `isGeometryFlipped = true`（PageCompositor.swift:191）

依据：

1. 经验证据一致：实验证明 flipped=false 正向 / flipped=true 镜像；live 路径
   非 flipped 正确；bug 现象与实验吻合。
2. 坐标系事实：宿主 y-up、baseFrame y-up（源码注释 + convert 计算），
   移除后子层坐标系与宿主一致，frame 直接映射，无几何歧义。
3. 最小变更：一行删除；合成层无子层，无代码依赖 flipped 几何
   （grep 确认 `isGeometryFlipped` 仅此一处）；`layerFramesForDiag` 返回
   宿主坐标 frame，不受影响。

### 备选：方案 B —— 保留 flipped + `layer.contentsTransform = CATransform3DMakeScale(1, -1, 1)`

仅当方案 A 被证明破坏隐藏依赖时回退（需先报 Main → Chief，不得自行切换）。
双机制叠加是本 bug 的温床，B 是回退不是首选。

### 拒绝：方案 C —— rasterize 改 y-up

影响所有 rasterize 消费者与既有像素断言，爆炸半径最大，违反最小变更。
