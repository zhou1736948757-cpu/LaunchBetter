## 1. 背景

用户实测"长名字滑动时仍显示全名"。T-021 诊断（Chief 裁定采纳，置信度 90%）：
- raster 截断于 104pt（labelRect = cellSize−4）
- live NSTextFieldCell 实际截断于 ~96.3pt（frame−7.7，私有绘制内缩；drawingRect/titleRect 均报 104 不可查询）
- 决定性证据："Affinity Designer 2.6"（98.72pt）raster 全名 100.5pt vs live 省略号 88.5pt
- T-019 修复有效（raster 确实截断），但没修"raster 与 live 截断宽度不同"

## 2. 修复方案（Chief 裁定，严格按此）

**采纳"常量 7.5"方案，拒绝"运行时实测"方案。**

### 实现
- `PageVisualRenderer.swift`：仅 drawLabel/drawCenteredText 的截断宽度 —— `truncationWidth = labelRect.width − 7.5`（≈ cellSize−11.5）
  - **保持 labelRect 与居中不变**（probe6 实证：raster @96.5 截断 → 94.0pt 居中 ≈ live 93.5pt，0.5pt 内对齐）
  - 建议以**显式参数**传入 drawCenteredText（默认 rect.width），避免把 NSTextFieldCell 特定内缩耦合进通用文本原语
  - 命名常量 + 注释：来源（NSTextFieldCell 私有绘制内缩，实测 7.5–7.7pt）、选择依据（probe6 验证）、依赖前提（label font 10pt 硬编码）、macOS 大版本升级需用 Workflow/evidence/T-021/ 的 probe4/5/8 重新测量
- 占位字母路径（truncatingTail:false）不受影响；文件夹标签走同一 drawLabel 自动同修

### 允许/禁止
- 允许改：`PageVisualRenderer.swift`（仅截断宽度）、`PageVisualRendererTests.swift`（新增测试）、`Workflow/` 记录
- **禁止改**：`AppCellView.swift`（live 路径——静止态是用户主要所见，方向必须是 raster 对齐 live，**不要顺手改 live**）；`PageCompositor.swift`；PageVisualKey/缓存签名；其他生产/测试文件
- 不得 commit/push/tag/release（需 Main 确认）

## 3. 缓存键

**不改**。截断宽度 = cellSize−11.5 是 cellSize 的纯函数（cellSize 已在 geometry 签名中），同键同图语义不变；PageVisualCache 是内存缓存重启即失效。常量注释注明：若未来 label 字体大小可配置，该常量变为字体函数，届时必须并入 key。
