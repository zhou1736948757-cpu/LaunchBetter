## 1. 背景

用户真实屏幕验收发现：Folder 大小已修复（T-019），但滑动时（compositor 合成层）Folder 背景的**毛玻璃效果消失**。用户要求：Folder 特效不要透视效果，只要模糊感觉，滑动/静止视觉一致。

## 2. 根因（Chief 决策确认）

- live 层：`FolderThumbnailView: NSVisualEffectView`（AppCellView.swift:679），`material = .hudWindow`（:688）、`blendingMode = .withinWindow`、`state = .active` —— **动态系统毛玻璃**
- raster 层：`drawFolderThumbnail`（PageVisualRenderer.swift:444）静态绘制：white fill 0.08 + border 0.38 + sheen 0.18→0.02 —— **无系统 blur/material**
- 视觉不可能一致 → 滑动时毛玻璃消失

## 3. 修复定义（Chief 修正版，严格按此）

**不是**"普通模糊视图"（raster 根本没有 blur，加 blur 反而引入新复杂度）。

**是**：移除动态系统毛玻璃，统一为**静态半透明 glass surface**。

### 实现
```swift
// 改前
private final class FolderThumbnailView: NSVisualEffectView
// 改后
private final class FolderThumbnailView: NSView
```
- **保留**：iconContainerLayer、sheenLayer、iconLayers × 9、corner radius、border、background
- **删除**：material、blendingMode、state
- **禁止增加**：CIFilter blur、CABackdropLayer、private CoreAnimation filters、background screenshot blur

### 顺手消除 semantic duplication（仅此）
新增 LaunchUI-internal 常量源，live/raster 共用：
```swift
enum FolderThumbnailStyle {
    static let backgroundAlpha: CGFloat = 0.08
    static let borderAlpha: CGFloat = 0.38
    static let sheenTopAlpha: CGFloat = 0.18
    static let sheenBottomAlpha: CGFloat = 0.02
}
```
- `AppCellView.swift` FolderThumbnailView 背景/border/sheen 用常量
- `PageVisualRenderer.swift` drawFolderThumbnail 同常量
- **禁止**：GlassStyleProtocol、FolderRenderingStrategy、MaterialProvider 等抽象

## 7. 验收标准

### 真实屏幕（用户）
