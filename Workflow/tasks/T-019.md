## 1. 背景

T-018 修复镜像后，用户真实屏幕验收发现 2 个新小 bug（rasterize 与 live 渲染契约不一致）：

- **(a) 名字截断不一致**：静止时（live 层 AppCellView）长名尾部截断；滑动时（compositor 合成层，rasterize 位图）显示全名。
- **(b) Folder 滑动时突然变大**：合成层文件夹缩略图比 live 层大。

## 2. 根因（Main 已定位，Worker 需复核）

### Bug a — `PageVisualRenderer.swift` `drawCenteredText`（约 :566）
超宽判断用 `CTLineGetBoundsWithOptions(line, [.useGlyphPathBounds])` —— `useGlyphPathBounds` 返回字形路径边界（不含字距/尾随空白），**宽度偏小** → `bounds.width > rect.width` 不触发 → 不截断 → 显示全名。live 层（AppCellView:293 `byTruncatingTail` + :294 `maximumNumberOfLines = 1`）截断正常。

### Bug b — `PageVisualRenderer.swift:155`
```swift
let folderChildPointSize = max(1, Int(FolderThumbnailMetrics(side: geometry.cellSize).iconSide.rounded(.down)))
```
rasterize 用 `geometry.cellSize`（整格大小，如 60）；live 层 `AppCellView.swift:636` 用 `FolderThumbnailMetrics(side: CGFloat(iconPointSize))`（图标大小，如 32）→ rasterize 文件夹缩略图偏大 → 滑动时 Folder 变大。
