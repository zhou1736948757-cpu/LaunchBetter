## 6. 行为不变论证

1. **取值条件等价**：旧路径要求 `modificationNanoseconds` 非 nil **且** `fileSizeBytes` 非 nil（各自 `try?` 查询 + key 非 nil）；新路径单次查询两 key，任一缺失/抛错 → nil。非 nil 当且仅当两值同时可得 —— 与旧的合取完全一致。
2. **公式逐位一致**：mtime = `UInt64(date.timeIntervalSince1970 * 1_000_000_000)`、size = `UInt64(size)`，与原两个私有函数逐字相同（新增测试 `mergedMetadataNormalFile` 用整秒 stamp 精确断言纳秒公式）。
3. **IconContentVersion 字段**：构造参数仅取值来源改变，字段名/类型/组合不变（iconResourceModificationNanoseconds、iconResourceSizeBytes、infoPlistModificationNanoseconds、bundleVersion）。
4. **信号优先级（§74）不变**：iconFile → Assets.car → Info.plist 回退三分支结构原样（改动只在分支内部取数），回退路径零改动。
5. **无性能声称**：纯结构优化（1 次 resourceValues 替代 2 次），未实测，不声称性能收益。
6. **调用面**：两私有函数无外部引用（grep 确认无残留），`make(appURL:infoPlist:infoPlistDate:)` 公开 API 签名不变，`AppDiscoveryService.swift` 调用点零改动。
