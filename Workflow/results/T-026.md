## 9. Deviations / 说明

1. **并发干扰（已解决）**：T-025 与 T-026 并发执行（max_worker_concurrency 2），T-025 中途状态使 Release 构建一度不可用（首次尝试 BUILD FAILED，错误全在 searchQuery 迁移领域，与 Wallpaper 无关）；本任务测试在树一致窗口内完成，全绿。T-025 收口（Main 提交 9b92d47）后，HEAD 上重跑 Release 确认 BUILD SUCCEEDED（exit 0）。
2. **红态为结构级**：行为保持型重构无"旧代码跑新测试失败"的运行时红态；红态 = 新测试在旧代码下无法编译（引用不存在的类型/init）。
3. **Provider 级测试环境分支**：`coldRenderReturnsBeforeDiskWrite` 在无壁纸源环境走安全回退分支（断言 `blurredWallpaper == nil`）；本机有真实壁纸源，完整路径真实执行（0.210s，HEAD 复跑）。
4. **`flush()` 契约**：不得在写队列内部调用（`queue.sync` 死锁风险）；生产路径不调用 flush（仅测试/收尾），Provider 生命周期内 writer 常驻。
5. **提交归属**：本任务代码由 Main 提交为 `2fd31ff`（Worker 未执行 commit；任务包禁止项仍满足——Worker 侧零 commit）。
